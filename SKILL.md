# DM reply on X

Reads, sums up, drafts. You send.

## Before you start
- Works with Claude plus a browser connection (Claude in Chrome), or with a thread you paste. Read only.
- Ask which thread (name or handle). Do not open the whole inbox unless asked.
- Say once at the start: opening a thread marks it as read on X.
- Voice: ask for `voice.md` (3 to 5 messages the user really wrote, plus words they never use). No voice file, no draft: ask for it first.

## Reading the thread
- With a browser connection: open x.com/messages. If X asks to log in, tell the user and stop. Open the thread, scroll up to the first message, then read down to the last one.
- Without a browser: ask the user to paste the full thread, oldest message first.
- Never guess a message you could not read. Say what is missing.

## Steps
1. If several threads: sort them.
   - Last message is "You: ..." : the ball is with them, skip unless asked.
   - A reaction was added: the thread is closed.
   - Their message has no answer: handle first.
2. Read the whole thread (see "Reading the thread"), oldest to newest. Never answer from the last message alone.
3. Sum up in 2 lines: where you left off, and what they asked or expect from the user.
4. Pick the situation.
   - Warm (a real exchange already happened): the first message only reconnects. A real topic from the thread, a specific thank you. No pitch, no link, no price.
   - Cold (never talked): do not draft a DM. Suggest one short public reply under one of their recent posts first.
5. Draft ONE next message. Short, plain words, in the user's voice, different wording for every person.
6. Show three things: the summary, the draft, and the line "Draft to validate, nothing is sent".

## Never
- Send, react, or follow up on your own. The user reads, edits and clicks send.
- Invent a fact about the person, a number or a quote. If unknown: "[to confirm]".
- Write more than one message at a time or remind someone who did not answer.
- Use em dashes.
